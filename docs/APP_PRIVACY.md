# App Store 개인정보 공개

2026-11-17 사용자의 최종 동의 후 [App Store Connect 개인정보 답변](https://appstoreconnect.apple.com/apps/6835714051/distribution/privacy)을 공개했다. 화면의 `数秒前に公開済み - IENTAE JUN` 상태로 완료를 확인했다. 앱 자체의 심사 제출이나 출시를 의미하지 않는다.

## 적용 구성과 근거

- 현재 광고 플러그인: `@capacitor-community/admob` 8.4.1, 해당 Package.swift의 Google Mobile Ads SDK 13.11.0, UMP 3.1.x. 메디에이션·Firebase·RevenueCat·Game Center·회원가입 기능은 현재 사용하지 않는다.
- 광고 요청은 `npa: true`, UMP의 `canRequestAds` 확인 후 초기화한다. 앱에서 ATT를 요청하지 않으며 IDFA 사용을 위한 Info.plist 문구도 설정하지 않았다. 비개인화 광고도 기기 식별자·광고 측정·진단 처리가 있으므로 ‘수집 없음’으로 답하지 않는다.
- [Google iOS 데이터 공개 안내](https://developers.google.com/admob/ios/privacy/data-disclosure): 대략적 위치, 기기 식별자, 제품 상호작용, 광고 데이터, 비사용자 관련 충돌 로그, 사용자와 연결되는 성능 데이터를 설명한다. 확인 시 문서는 13.12.0 기준이므로 출시 빌드에 포함되는 13.11.0 SDK의 개인정보 리포트와도 대조해야 한다.
- [Google 광고 제공 모드](https://developers.google.com/admob/ios/privacy/ad-serving-modes)와 [Apple 분류·수집·추적 정의](https://developer.apple.com/app-store/app-privacy-details/)도 참고했다.
- 기기에만 보관되는 게임 저장, XP, 실수/힌트 기록과 StoreKit 검증 권한은 자체 서버나 분석 서비스에 전송하지 않는다. 카드 정보는 Apple이 처리하며 앱은 받지 않는다. 이에 게임플레이 콘텐츠·구매 내역·결제 정보는 별도 수집 항목에서 제외했다.

실명·이메일·연락처·정밀 위치·건강·사진·검색 기록 등의 수집은 선택하지 않았다. ‘연결’에는 계정 이름뿐 아니라 기기를 통해 연결되는 경우도 포함한다. 충돌 로그는 Google 문서의 비사용자 관련 로그 설명을 반영했다.

추적 ‘아니요’는 현재의 ATT 미요청·비개인화 광고·추가 추적 SDK 없음 구성에 대한 판단이다. `npa: true` 하나만으로 모든 광고 측정이 Apple의 추적 정의에서 제외된다고 보장하는 것은 아니다. Mac에서 실제 SDK의 개인정보 리포트, UMP 메시지(특히 IDFA 설명 메시지), 광고 제공·계정 설정 및 통신 동작을 확인한다. 다른 회사의 데이터와 결합해 광고 타기팅·개인별 광고 효과 측정을 하게 된다면 공개 답변과 ATT 구현을 함께 변경해야 한다.

## iCloud 추가 후 재검토 대기

위 공개 표는 iCloud 구현 전의 답변이다. 이후 선택형 CloudKit 개인 저장소 보관 코드를 추가했다. 사용자가 저장 버튼을 누르면 프로필·XP·배지·퍼즐 보드·실패/힌트/시간 이력과 저장 시각을 Apple의 private database에 전송한다. 구매 권한·광고 빈도·동의 정보는 제외한다. 개발자 소유 서버나 분석 서비스로는 보내지 않는다. 아직 실제 Apple 컨테이너 설정 및 업로드를 검증하지 않았다.

이제 게임 기록 전체를 ‘기기에만 보관’한다고 설명해서는 안 된다. 출시 전에 실제 CloudKit 개인 저장소 접근 권한과 Apple의 수집/선택적 공개 예외 정의를 대조하여 게임플레이 콘텐츠·제품 상호작용·기타 사용자 콘텐츠 등의 공개 필요 여부를 확정하고, 필요한 경우 위 공개 답변을 갱신한다. 운영 방침이 선택형 iCloud 저장 및 삭제 방법을 설명하는지도 확인한다. 기존 개인정보 답변은 이번 코드 변경에서 다시 공개하지 않았다.

## 출시 전 및 변경 시 확인

실제 iPhone 빌드의 SDK 개인정보 매니페스트/리포트와 공개 답변을 대조한다. 광고 모드·동의 화면·SDK 버전·광고 네트워크를 바꾸거나 Firebase/외부 랭킹/클라우드 저장/구매 서버를 추가하면 다시 검토한다. 자체 앱의 `PrivacyInfo.xcprivacy`에 있는 UserDefaults API 사유는 이 웹 설문과 별개다.
