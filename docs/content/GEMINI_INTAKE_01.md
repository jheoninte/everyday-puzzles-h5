# Gemini 응답 확인 — 2026-11-17

첨부 응답은 `Everyday Puzzles Studio`라는 단일 HTML 프로토타입이다. 요청한 출시 콘텐츠 JSON이 아니다.

- `schemaVersion`, `guessWords`, `launch-01`~`launch-20`이 없다.
- `DAILY_PACKS`에 2026-11-17~2026-11-22의 6일치 예시를 포함한다.
- 한국어 UI이며 HubGame이 없으면 로컬 저장도 동작하지 않도록 설계했다는 설명이 있다. 현재 영어 iOS 앱의 로컬 저장·네이티브 서비스 구성과 다르다.
- 현재 요구한 20팩 및 공통 500개 이상 단어 목록을 충족하지 못하므로 앱 코드나 공개 콘텐츠에 적용하지 않았다. 첨부 코드는 실행하지 않았다.

`docs/GEMINI_CONTENT_PROMPT.md`를 보강했다. 이전 HTML 응답을 반복하지 않고 기존 앱용 영어 JSON 데이터만 반환하도록 명시한다. 전체 코드 블록을 Gemini에 다시 전달하고 JSON 결과를 받아야 한다.

로컬에서 생성한 유일해답 스도쿠 20개와 콘텐츠 검증·구성 도구는 그대로 유지한다. 공개 콘텐츠는 현재 7팩/28문제다.
